# 11 — الأمان

## نموذج التهديد

- **مراقب سلبي:** يرى SNI الخاص بـTLS والتوقيت/الحجم (خفّف بـCDN والحشو عند الحافة).
- **فاحص نشط:** يتصل بدون السر (يجب ألا يتعلم شيئًا — انظر أدناه).
- **عميل خبيث:** يحاول استنزاف الذاكرة/المعالج أو الالتفاف نحو مضيفين داخليين.

خارج النطاق: اختراق النقاط الطرفية، وربط الحركة العالمي، واختراقات حافة TLS.

## ما ينفذه هذا المشروع أصلًا

| الضبط | الموضع | التفصيل |
|-------|--------|----------|
| مقارنة الأسرار بأمان زمني | `safeEqual` ‏(VLESS) و`safeEqual` ‏(Trojan) | ‏`crypto.timingSafeEqual` مع فحص الطول أولًا |
| سقف الهيدر | ‏VLESS V2 ‏`MAX_HEADER_SIZE=4096` | إغلاق قبل تخزين المزيد |
| سقف إطار WS | كلا الخادمين | `maxPayload: 16 MB` |
| مهلة الاتصال | ‏VLESS V2 ‏`connectTCP(..., 10000)` | يُمسح المؤقت عند الاتصال **والخطأ** |
| مطابقة تامة للمسار | معالجا الترقية | المسار الخاطئ ← `socket.destroy()` بدون لافتة |
| لا تسريب معلومات | مسارات الخطأ | ‏VLESS يرسل `[ver, code]` فقط؛ وTrojan لا يرسل شيئًا |
| تنظيف قسري | `close()` والتنظيف لكل اتصال | إنهاء WS وتدمير TCP و`closeAllConnections?.()` |
| ‏TS صارم | `tsconfig` | ‏`strict` ‏+ `noUncheckedIndexedAccess`؛ وكل فهرسة محروسة |

## قيود معروفة (كن صريحًا في مراجعات التشغيل)

- **لا TLS داخل العملية** — فـWS غير مشفر على الشبكة المحلية إذا كان البروكسي
  العكسي بعيدًا.
- **اتصال Trojan بلا مهلة** (الافتراضي للنظام)؛ وأضف واحدة إذا عرضته مباشرة.
- **يسجل Trojan بصمة كلمة المرور** عند بدء التشغيل (`Password SHA224: ...`) —
  والبصمة *هي* الاعتماد. نظّف هذا السجل أو عطّله في الإنتاج.
- **لا تحديد معدل / fail2ban** — أضفه عند الحافة (فـUUID/كلمة المرور الخاطئة
  حاليًا تسجل وتغلق فقط).
- **خادم V1 القديم** (`servers/vless-ws.ts`) يغلق الهيدرات المجزأة بدل تخزينها —
  لا توجه إليه حركة الإنتاج.
- **لا UDP** — فالعملاء طالبو UDP يتلقون خطأ/إغلاقًا؛ ووثّق هذا للمستخدمين.

## قائمة التشغيل

- [ ] ‏TLS عند الحافة (Caddy/Nginx) مع HSTS وإعادة `:80 ← :443`.
- [ ] ‏`websocket.path` مميز يصعب تخمينه لكل نسخة.
- [ ] ‏UUID عشوائي لكل خادم VLESS؛ وكلمات مرور Trojan عشوائية (32+ حرفًا).
- [ ] اربط `listen` على `127.0.0.1` عند وجود بروكسي عكسي محلي.
- [ ] قيّد الخروج إذا وجب منع العملاء من بلوغ الشبكات الداخلية (فالبروكسي يتصل
      بأي `host:port` يطلبه العميل بما فيه `169.254.169.254`).
- [ ] اشحن السجلات مركزيًا؛ ونبّه عند دفعات `Invalid UUID/password`.
- [ ] ‏`bun test` و`npx tsc --noEmit` خضراوان في CI قبل النشر.
