# 08 — مواصفة VMess (مرجعية)

> **غير منفذة** في proxy-suite. ومشمولة هنا ليفهم المشغّلون منظومة V2Ray الأوسع
> وليهاجروا العملاء القدامى إلى VLESS.

## الفكرة

VMess (بروتوكول V2Ray الأصلي) يضيف **تشفيرًا موثقًا مقيدًا بالزمن**: فكل جلسة
تستخدم مفتاحًا جديدًا مشتقًا من UUID المستخدم + الطابع الزمني، فتفشل الإعادات
خارج نافذة ±120 ثانية. وهو أقوى من UUID الساكن في VLESS وأثقل من تصميم VLESS
عديم التشفير.

## مخطط الطلب (TCP + ‏AEAD)

```
auth        : ‏16 بايتًا (معتمد على MD5 والزمن — يمنع الإعادة)
header      : مغلق بـAEAD ‏{
                version    : بايت (0x01)
                IV         : ‏16 بايتًا
                key        : ‏16 بايتًا
                responseV  : بايت
                option     : بايت (البت 0: تدفق المقاطع، البت 2: حشو عام)
                paddingLen : ‏1-2 بايت (P)
                security   : بايت (0:لا يوجد 1:aes-128-gcm ‏2:chacha20-poly1305 ‏3:لا يوجد مختوم)
                reserved   : بايت
                cmd        : بايت (0x01 للـTCP | ‏0x02 للـUDP | ‏0x03 للـmux)
                port       : بايتان
                atyp+addr  : بنمط SOCKS ‏(0x01/0x02/0x03 — بترقيم VLESS)
              }
body        : تدفق مقاطع، كل مقطع مختوم بـAEAD بعدّاد متزايد
```

اشتقاق المفتاح (مبسط):

```
key = MD5(uuid_bytes || "c48619fe-8f02-49e0-b9e9-edf763e17e21")
auth = HMAC-MD5(key, timestamp_be64)  // يُتحقق ضمن ±120 ثانية + جدول انحراف
```

## أنواع الأمان

| القيمة | الشفرة | ملاحظات |
|--------|--------|----------|
| `0` / `3` | لا يوجد | للاختبار فقط |
| `1` | ‏AES-128-GCM | الافتراضي، صديق للعتاد |
| `2` | ‏ChaCha20-Poly1305 | للجوال / بدون AES-NI |

## ‏VMess مقابل VLESS

|  | ‏VMess | ‏VLESS |
|--|--------|--------|
| الهوية | ‏UUID + طابع زمني (مقاوم للإعادة) | ‏UUID ساكن |
| التشفير | ‏AEAD لكل جلسة | لا يوجد (يُفوَّض إلى TLS) |
| العبء | أعلى (ختم كل مقطع) | أدنى |
| ‏UDP | نعم | في المواصفة نعم، وهذا المشروع لا |
| التوصية | توافق قديم | المنشورات الجديدة |

## شكل رابط العميل (للمرجع)

```
vmess://<json-مشفّر-base64>
# ‏JSON ‏: { v:"2", ps:"name", add:"host", port:443, id:"<uuid>",
#         aid:0, scy:"auto", net:"ws", type:"none", host:"host",
#         path:"/vmess", tls:"tls", sni:"host" }
```

مسار الهجرة: أبقِ UUIDs وبدّل نوع الخادم إلى `vless-ws` وغيّر العميل إلى
`encryption=none` وأعد إصدار الروابط عبر `--url`.
